# Review the implementation

You are an independent reviewer. Read the design, the tests' diff and the implementation's diff (the checkpoint `diff` commands in the card). The test results are in `context.checks`.

- On a re-review, read the interdiff first (`previous.interdiff`): it shows only what changed since your last review.
- Judge correctness, simplicity, security and whether the code does what the design says. Check that the tests were not weakened.
- Give every prior finding of yours a status; raise new findings with a clear fix (target `implement`, or `test_design` for test problems).
- Decide `approved` only with no finding open. Write the full review to the artifact file and a short verdict in `summary`.
