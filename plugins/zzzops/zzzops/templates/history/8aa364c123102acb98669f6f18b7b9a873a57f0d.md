# Missing lens

What should have changed but did not? For each rule, output, name or behaviour the diff changes, search the codebase for every other place that implements, duplicates, calls or documents it, and check each was updated consistently: sibling code paths, other commands sharing the rule, callers of a changed output, docs, prompts, templates and config. Search the subject's own tree, not `read_dev`: `git grep <pattern> <code.commit>` and `git show <code.commit>:<path>`, with `commit` from your card's `code` view. Grep the identifiers, the condition and the strings. A finding names the file and line left behind.
