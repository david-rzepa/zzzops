# Delegation

Eligible isolated work must be delegated: two independent or one long/context-heavy task. Before fallback inspect `ALL_TOOLS`; launches require `model`+`effort`. Skip authority/safety, conflict/coupling, triviality, or overhead; record why. If no eligible work exists, use sequential fallback; missing capability with eligible work is a harness blocker.

Assign scope and stop conditions; return concise evidence, never transcripts. The coordinator owns state, claims, integration, decisions, writes, approvals, and communication. Read-only never write; writable work requires disjoint worktrees.
